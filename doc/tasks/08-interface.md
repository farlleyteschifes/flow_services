# 08 — Interface da aplicação

## Objetivo

Construir a experiência de uso mobile-first para preenchimento rápido durante o culto.

## Escopo

- Criar tela de login.
- Criar fluxo de seleção de data e tipo de culto.
- Criar formulário do culto com frequência, louvores e participantes.
- Usar botões grandes e acessíveis para incremento/decremento.
- Adicionar autocomplete para membros e louvores.
- Indicar visualmente alterações salvas, carregamento e erros.
- Adicionar botão explícito “Atualizar” para recarregar o culto.
- Adicionar alteração de senha, logout e exclusão de culto com confirmação.
- Manter todos os textos da interface em português brasileiro.

## Critérios de aceite

- O formulário pode ser utilizado confortavelmente em celular.
- Não existe botão geral de “Salvar dados”.
- O usuário consegue distinguir estado salvo, carregando e erro.
- Dados atualizados por outra pessoa aparecem após clicar em “Atualizar”.
- Campos e controles possuem labels, foco visível e suporte básico a teclado/leitor de tela.
